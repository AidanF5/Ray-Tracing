Welcome to my rendering project

Initially based off of Ray Tracing In One Weekend

The goal of this project is to extend it as far as possible to create a realistic renderer of many difference scenes

This project includes CPU code allowing for easy extensibility and modularity
It also includes GPU code written in GLSL to give a fast render


Next steps:
    Change CPU code to output a PNG instead
    Add the different camera settings to the GPU code
    Add a light material which emits light and removing the sky gradient
    Add planes, cylinders, tori and cones
